# adaptive-interview-platform
# Платформа адаптивной подготовки к техническим собеседованиям

**Год:** 2026–2027 учебный год

## О проекте

Проект представляет собой веб-платформу для самостоятельной подготовки к техническим собеседованиям в сфере разработки программного обеспечения. На первом этапе основное внимание уделяется подготовке frontend-разработчиков: JavaScript, TypeScript, React и базовым алгоритмам.

Ключевая идея — **адаптивный подбор заданий**. Система должна учитывать результаты пользователя, определять темы, требующие дополнительной практики, и рекомендовать следующие задания с подходящим уровнем сложности.

> **Статус:** проектирование. Описанные ниже функции и технологии запланированы и могут уточняться в процессе разработки ВКР.

## Цель работы

Спроектировать и разработать веб-платформу, обеспечивающую оценку знаний пользователя и адаптивный подбор учебных заданий по результатам его подготовки.

## Основные задачи

1. Проанализировать существующие решения для подготовки к техническим собеседованиям.
2. Определить функциональные требования и спроектировать архитектуру системы.
3. Разработать интерфейс, серверную часть и структуру базы данных.
4. Реализовать прохождение заданий и сохранение результатов.
5. Разработать алгоритм адаптивного подбора заданий на основе истории ответов.
6. Провести тестирование системы и оценить качество работы алгоритма.

## Планируемые возможности

- Регистрация, авторизация и профиль пользователя.
- Каталог вопросов и заданий по темам и уровням сложности.
- Прохождение тестов и получение обратной связи.
- Сохранение ответов и истории прохождения.
- Оценка прогресса и определение слабых тем.
- Рекомендации следующих заданий на основе результатов пользователя.
- Панель статистики подготовки.

## Принцип адаптивной подготовки

1. Пользователь выбирает направление подготовки и выполняет задания.
2. Система сохраняет ответы и результаты по каждой теме.
3. На основании успешности и сложности заданий обновляется оценка знаний.
4. Алгоритм предлагает следующие задания с учётом тем, нуждающихся в повторении.
5. После новых попыток оценка пересчитывается, а рекомендации уточняются.

На начальном этапе предполагается алгоритм на основе правил и показателей успешности. Применение машинного обучения **не является обязательным** и будет рассматриваться отдельно при необходимости.

## Предполагаемый стек технологий

| Часть проекта | Технологии | Назначение |
| --- | --- | --- |
| Frontend | React, TypeScript | Пользовательский интерфейс |
| Работа с API | TanStack Query | Запросы, кэширование, управление серверными данными |
| Backend | Node.js, Express | REST API и серверная логика |
| База данных | PostgreSQL | Пользователи, задания, попытки, прогресс |
| Инструменты | Git, Docker | Контроль версий и воспроизводимое окружение |

Окончательный стек может быть скорректирован при проектировании.
